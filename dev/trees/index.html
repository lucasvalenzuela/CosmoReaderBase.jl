Merger Trees

Tree Type

CosmoReaderBase.AbstractMergerTree — Type
abstract type AbstractMergerTree{S} end

Abstract type representing the merger tree of a simulation S<:AbstractCosmoSimulation.

Subtypes have to implement the following methods:

  • get_simulation(::AbstractMergerTree): if simulation is not a field

This is not exported.

source
CosmoReaderBase.get_simulation — Method
get_simulation(tree::AbstractMergerTree)

Returns the simulation to which the merger tree belongs.

By default returns tree.simulation.

Halo & Merger Tree Node Types

CosmoReaderBase.AbstractMergerTreeNode — Type
abstract type AbstractMergerTreeNode end

Abstract type representing a halo in the merger tree of a simulation.

Subtypes have to implement the following methods:

  • has_prop(::AbstractMergerTreeNode)
  • read_prop_simunits(::AbstractMergerTreeNode, ::Symbol): not exported
  • convert_halonode_prop: not exported
  • get_halo(::AbstractMergerTreeNode)
  • get_subhalo(::AbstractMergerTreeNode)
  • get_tree_node(::AbstractMergerTree, ::Subhalo)
  • get_tree_node(::AbstractMergerTree, ::Halo): if the tree represents Halos
  • first_progenitor
  • first_progenitor_at: optional for performance
  • descendant
  • next_progenitor_sibling
  • prev_progenitor_sibling: optional for performance
  • first_progenitor_sibling: optional for performance
  • first_progenitors: optional for performance
  • first_progenitors_and_self: optional for performance
  • descendants: optional for performance
  • descendant_at: optional for performance
  • descendants_and_self: optional for performance
  • direct_progenitors: optional for performance
  • progenitor_siblings: optional for performance
  • get_tree(::AbstractMergerTreeNode): if tree is not a field
  • get_snapshot(::AbstractMergerTreeNode): if snapshot is not a field
  • Base.:(==): for some of the default traversal methods to work

This is not exported.

CosmoReaderBase.read_prop — Method
read_prop(halonode::AbstractMergerTreeNode, prop; units=:physical, unitful=false)

Returns the property of the halo node.

Keyword arguments

  • units::Symbol=:physical: has to be :sim, :physical, or :comoving for simulation, physical, or comoving units, respectively
  • unitful::Bool=false: whether unitful units should be added to the properties or not. This is ignored if units=:sim.

CosmoReaderBase.first_progenitor_sibling — Function
first_progenitor_sibling(halo::AbstractHalo) -> AbstractHalo
first_progenitor_sibling(halonode::AbstractMergerTreeNode) -> AbstractMergerTreeNode

Returns the first or main progenitor sibling of the halo, or nothing if it does not exist.

First progenitor sibling means the main halo that has the same descendant as the passed halo, i.e., the halo that the passed halo merged into. The sibling progenitor is not necessarily from the same snapshot as the passed halo.

CosmoReaderBase.direct_progenitors — Function
direct_progenitors(halo::AbstractHalo)
direct_progenitors(halonode::AbstractMergerTreeNode)

Returns an iterator over all direct progenitors of the passed halo starting with the largest.

Note it is possible that not all direct progenitors are from the same snapshot due to halos not always being identified in all snapshots. It is also possible that the halos following the first are not ordered by size or mass.

Also see progenitor_siblings.

source
CosmoReaderBase.progenitor_siblings — Function
progenitor_siblings(halo::AbstractHalo)
progenitor_siblings(halonode::AbstractMergerTreeNode)

Returns an iterator over all smaller halos that merge into the same descendant of the passed halo node.

Note it is possible that not all progenitor siblings are from the same snapshot as the passed halo due to halos not always being identified in all snapshots. Depending on the merger tree, these will not necessarily be ordered by size or mass.

Also see direct_progenitors.

Developer's API

In the default implementation, only subhalos are assumed to have equivalent halo nodes in a merger tree. If this is not the case, get_halo(::AbstractMergerTreeNode) and get_tree_node(::Halo) have to be implemented.

CosmoReaderBase.read_prop_simunits — Method
read_prop_simunits(halonode::AbstractMergerTreeNode, prop::Symbol)

Returns the halo property in simulation units.

Contrary to read_prop, this function always reads in the value from the simulation.

This is not exported.

source
CosmoReaderBase.convert_halonode_prop — Function
convert_halonode_prop(val, prop::Symbol, halonode::AbstractMergerTreeNode; units::Symbol, unitful::Bool)

Returns the halo node's property or properties converted from simulation units to the specified units.

For the allowed values of units and unitful, see read_prop. The passed value can be a scalar value (Number) or an array of values (AbstractArray).

This is not exported.
