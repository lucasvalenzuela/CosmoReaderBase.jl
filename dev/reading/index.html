Reading Particles

CosmoReaderBase.read_particles — Function
read_particles(snapshot::AbstractSnapshot[, type::Symbol[, props]]) -> SimulationParticleCollection
read_particles(snapshot::AbstractSnapshot, typeprops::AbstractVector{<:Union{Tuple,Pair}}) -> SimulationParticleCollection

Returns particles in a snapshot with all or the specified properties.

If the particle type is given, only the particles of that type are read, and if one or more properties are passed through props (as a Symbol or AbstractVector of Symbols), only those properties are read.

The value of typeprops is a vector of tuples or pairs in the format of [(:dm, [:pos, :vel]), (:gas, [:pos, :mass])] or [:dm => [:pos, :vel], :gas => [:pos, :mass]].

Keyword arguments

  • units::Symbol=:physical: has to be :sim, :physical, or :comoving for simulation, physical, or comoving units, respectively
  • unitful::Bool=false: whether unitful units should be added to the properties or not. This is ignored if units=:sim.
  • verbose::Bool=false: whether the output should be verbose or not

read_particles(snapshot::AbstractSnapshot, typeprops::AbstractVector{<:Union{Tuple,Pair}}, ids::AbstractVector[, centerpos, radius]) -> SimulationParticleCollection

Returns the particles with the given IDs in a snapshot with the specified properties.

If a center position and radius are given, only the particles in at least the volume of such a surrounding cube are read and filtered by their IDs. Particles are shifted across the box borders if the volume reaches across the borders and the box is periodic. Depending on the implementation it is also possible that a larger volume is read in first and particles outside the radius are read in.

Keyword arguments

  • shift_to_center=false: if true, the particle positions are shifted such that centerpos becomes the origin. Particles are shifted across the box borders if the box is periodic. This leads to an error if centerpos is not given.

For the format of typeprops and further possible keywords, see read_particles(::AbstractSnapshot).

read_particles(snapshot::AbstractSnapshot, typeprops::AbstractVector{<:Union{Tuple,Pair}}, geo::AbstractCosmoGeometry) -> SimulationParticleCollection
read_particles(snapshot::AbstractSnapshot, typeprops::AbstractVector{<:Union{Tuple,Pair}}, geo::CosmoHyperrectangle; exact=false) -> SimulationParticleCollection

Returns the particles within a given volume in a snapshot with the specified properties.

Particles are shifted across the box borders if the volume reaches across the borders and the box is periodic.

If exact is false for a hyperrectangle (e.g., rectangle or cuboid) volume, the particles can also lie slightly outside the defined volume. This is particularly relevant for simulations with a Peano-Hilbert indexing method.

Keyword arguments

  • posprop=:pos: name of the position property by which to filter the read-in particles
  • shift_to_center=false: if true, the particle positions are shifted such that centerpos becomes the origin. Particles are shifted across the box borders if the box is periodic.

For further possible keywords, see read_particles(::AbstractSnapshot).

CosmoReaderBase.read_particles! — Function
read_particles!(halo::AbstractHalo, typeprops::AbstractVector{<:Union{Tuple,Pair}}[, minradius])
read_particles!(halo::AbstractHalo, typeprops::AbstractVector{<:Union{Tuple,Pair}}, sphere::CosmoSphere)
read_particles!(halo::AbstractHalo, pc::AbstractSimulationParticleCollection[, typeprops::AbstractVector{<:Union{Tuple,Pair}}][, minradius])

Returns the particles within the given halo with the specified properties.

The first method reads out the particles including at least all the particles within the given radius (times the scaling factor rscale, see the keyword arguments), depending on the most performant read-out method. The second method in contrast filters the particles to only include those located within the radius of the CosmoSphere (created by CosmoSphere(radius)).

For the third method, the particles are purely read from the particle collection pc. If typeprops are not given, all available particle types and properties are filtered. The units passed should be the same as the particle collection was read in with.

Particles are shifted across the box borders if the halo reaches across the borders and the box is periodic.

Optional arguments

  • radius: A Number or a radius property of the halo as a Symbol to indicate what cubic volume around the halo's center should be read in. When a Number is passed, the units are assumed to be identical to the ones requested of the particles to read in.

Keyword arguments

  • rscale::Real=1: If radius given, it is multiplied by rscale to determine the cubic volume to read in. This is especially relevant for when radius is a halo property.
  • shift_to_center=false: if true, the particle positions are shifted such that centerpos becomes the origin. Particles are shifted across the box borders if the box is periodic. This leads to an error if centerpos is not given.
  • readall::Bool=false: if true, all particles within a cube with the given radius are returned instead of only the particles belonging to the halo. This leads to an error if centerpos is not given.

For further possible keywords, see read_particles(::AbstractSnapshot).

read_particles_in_cuboid(snapshot::AbstractSnapshot, typeprops::AbstractVector{<:Union{Tuple,Pair}}, lowerleft::AbstractArray, upperright::AbstractArray) -> SimulationParticleCollection

Returns the particles within the cuboid given by the lower left and upper right corner in a snapshot with the specified properties. Particles are shifted across the box borders if the cuboid reaches across the borders and the box is periodic.

Keyword arguments

For the possible keywords, see read_particles(::AbstractSnapshot), and additionally:

  • shift_to_center=false: if true, the particle positions are shifted such that centerpos becomes the origin. Particles are shifted across the box borders if the box is periodic.

This is not exported.

Developer's API

At least the following functions have to be implemented for implementations of AbstractCosmoSimulation. Further predefined methods can also be implemented to improve performance.
