Halos and Subhalos

Particle Data

Any AbstractHalo contains the particles containing to a halo and the corresponding snapshot. A Halo can be created if its ID is known or from reading AbstractHalos from the simulation. The particles of a Halo or Subhalo can be read in from a simulation with read_particles!.

A Halo's particle collection belonging to a snapshot of a cosmological simulation.

Individual properties of the Halo can be saved in props. The reading routines will use props to save properties in simulation units. To get the values converted to units, read_prop should be used.

The following methods have to be implemented for Halo{<:AbstractSnapshot}:

  • get_subhalos
  • get_main_subhalo

CosmoParticles.translate_periodic — Function
CosmoParticles.translate_periodic(pc::AbstractSimulationParticleCollection, centerpos::AbstractVector{<:Number}, posprop=:pos)

Translates the particles in-place periodically along the simulation box borders to minimize the distances to centerpos.

The particle positions are not shifted if the simulation box is not periodic.

Keyword arguments

  • units::Symbol=:physical: has to be :sim, :physical, or :comoving for simulation, physical, or comoving units, respectively
  • unitful::Bool=false: whether unitful units should be added to the properties or not. This is ignored if units=:sim.

Halo/Subhalo Properties

AbstractHalos are an AbstractParticles subtype to provide a simple interface for reading and working with halo properties. Halos and Subhalos can be obtained through read_halos and read_subhalos. While the particles of an individual halo (e.g. DM or gas particles) cannot be saved in this type, a Halo or Subhalo is created when indexing into an AbstractHalos, provided the property id is available:

halos::Halos
halo = halos[1]   # first Halo, into which particles can be read with read_particles!
halo isa Halo     # true

Additionally, iterating over AbstractHalos returns individual AbstractHalo objects, i.e., Halo or Subhalo:

halos::Halos
for halo in halos
    halo isa Halo  # true
end
