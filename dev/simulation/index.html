Simulation

A cosmological simulation of type CosmoSimulation will generally consist of the path it is located at and of a configuration struct of type AbstractCosmoReaderConfig, which typically contains the information on the snapshot naming system, on the available particle types, and on the property names and units. Different backends for concrete simulation types implement this API individually.

General Simulations

CosmoReaderBase.AbstractCosmoSimulation — Type
abstract type AbstractCosmoSimulation end

Abstract type for representing a cosmological simulation.

Subtypes have to implement the following methods:

  • has_tree
  • get_tree
  • get_snapshot
  • get_nearest_snapshot
  • get_first_snapshot
  • get_last_snapshot
  • snapshots
  • cosmology
  • isperiodic
  • is_cosmological
  • boxcorners
  • boxlengths
  • get_name
  • get_config: if config is not a field
  • get_dir: if dir is not a field

This is not exported.

Simulations with Configs

CosmoReaderBase.AbstractCosmoReaderConfig — Type
abstract type AbstractCosmoReaderConfig end

Abstract type for representing different configurations for cosmological simulations.

Subtypes have to implement the following methods:

  • particle_properties
  • halo_properties
  • subhalo_properties

This is not exported.

source
CosmoReaderBase.CosmoSimulation — Type
struct CosmoSimulation{C<:AbstractCosmoReaderConfig,T} <: AbstractCosmoSimulation
    config::C
    dir::T
end

Cosmological simulation with an associated configuration object and a main directory.

The methods defined for AbstractCosmoSimulation need to be implemented for concrete types of configuration types, e.g., by has_tree(::CosmoSimulation{ConcreteCosmoReaderConfig}).

CosmoReaderBase.particle_properties — Function
particle_properties(config::AbstractCosmoReaderConfig)
particle_properties(sim::AbstractCosmoSimulation)
particle_properties(snapshot::AbstractSnapshot)

Returns the available particle properties as a NamedTuple vector.

The table has the following column names:

  • prop: the property name as saved in the simulation output
  • unit: the unit of the property, or nothing if unitless
  • identifiers: the possible identifiers of the property
  • rownames: row names of the properties, else nothing
  • available: true, false, or missing, depending on whether the property is actually available for the current simulation at hand

Snapshots

CosmoReaderBase.AbstractSnapshot — Type
abstract type AbstractSnapshot{AbstractCosmoSimulation} end

Abstract type for representing simulation snapshots in time.

Usually has the fields sim::<:AbstractCosmoSimulation and id.

Subtypes have to implement the following methods:

  • prev_snapshot
  • next_snapshot
  • CosmoParticles.redshift
  • simulation_time_isolated
  • get_simulation if sim is not a field
  • get_snapshotid if id is not a field

This is not exported.

Cosmology.lookback_time — Function
Cosmology.lookback_time(snapshot::AbstractSnapshot)

Returns the lookback time of the snapshot, or 0 if the simulation is not cosmological.

See Cosmology.jl.

Keyword Arguments

  • units::Symbol=:physical: has to be :sim, :physical, or :comoving for simulation, physical, or comoving units, respectively (note that physical and comoving will be the same for times)
  • unitful::Bool=false: whether unitful units should be added to the properties or not. This is ignored if units=:sim.
